# __PROJECT_SLUG__ — a worldfilm project

Start: fill BRIEF.md, brand.md, MOTION.md and facts.json, and set duration, sizes, fps, gates, delivery, variants
and the audio route in shotspec.json. Put references in references/, footage in footage/, data in data/, any
supplied music in assets/music/. Then open this folder in Codex or Claude Code and say "use worldfilm on this
brief". PROGRESS.md is the resumable state; GAUNTLET.jsonl the critic ledger.

Layout: world.js (the simulated world: render(cam), anchors(cam), dispose; per-composition options) · film/data.js
(generated by tools/build.py: the one timeline and the events(t) table) · film/camera.js (pose graph, optional
rest drift, framing targets, projector: pure, no DOM) · film/main.js (HUD, label placement via film/place_label.js,
the paused timeline) · index.html (HyperFrames root) · compositions/<variant>.html (optional extra sizes) ·
tools/build.py (one source of truth; exits 2 while placeholders remain), tools/sweep.mjs (per-frame checks; exits 2
until configured), tools/srt.py · audio/make_cues.py (synthesized route only) · gates/ (measured reports) ·
renders/ (drafts, masters, poster, SRT) · build.sh (stages 2-9 from shotspec.json; PRINT_CONFIG=1 shows the
settings it reads; a skipped gate fails it).
