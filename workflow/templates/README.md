# __PROJECT_SLUG__ — a worldfilm project

Start: fill BRIEF.md, brand.md, MOTION.md and facts.json; put references in references/, footage in footage/,
data in data/, music in assets/music/. Then open this folder in Codex or Claude Code and say
"use worldfilm on this brief". PROGRESS.md is the resumable state; GAUNTLET.jsonl the critic ledger.

Layout: world.js (the simulated world: render(cam), anchors(cam) with -right/-left post variants, dispose; options
per composition such as portalFade) · film/data.js (generated by tools/build.py: the one timeline, the events(t)
table) · film/camera.js (pose graph, rest drift, framing targets, readout, projector: pure, no DOM) · film/main.js
(HUD, label placement rule, the paused GSAP timeline) · index.html (HyperFrames root) · compositions/<variant>.html
(each extra aspect, gated on its own render) · tools/build.py (one source of truth), tools/sweep.mjs (every frame:
numbers recomputed independently, labels clear their targets, framing targets settle), tools/srt.py ·
audio/make_cues.py -> audio/cues.json (the cue sheet from the event table) · gates/ (every measured report;
gates/master-<slug>-<size>/ per delivered file) · renders/ (drafts, masters, poster, SRT) · build.sh (the whole
sequence, stages 2-9; a skipped gate fails it).
