# Optional productions

This folder contains archived films and their project-specific code, sources and review evidence. Nothing here is
installed with the skill, copied into new projects, or imported by the required test suite.

- [Archived spatial film](block-space/): a historical production, with its own README, assets, content model,
  verification results and release downloads.

The workflow and starter live in `../workflow` and `../studio/projects/_template`. Use those for a new project.
